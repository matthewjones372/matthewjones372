### Hi, I'm Matt

I write typed functional code on the JVM, in Scala and Kotlin, and some Python for ML.

Most of what's here is me poking at ideas to see how they hold up: a few small Kotlin libraries (HTTP, effects on virtual threads, load testing, compile-time mapping), a [petshop](https://github.com/matthewjones372/petshop) that tries them out together, a [ZIO HTTP API over four film universes](https://github.com/matthewjones372/starwars-api) in Scala, and some [ML work](https://github.com/matthewjones372/winning-ticket-search) from my MSc. There's also [verdict](https://github.com/matthewjones372/verdict), a Scala 3 rules engine that reads rules from lambdas with a macro, and [estate](https://github.com/matthewjones372/estate), a TypeScript dashboard that puts what you need for each service on one page.

Scala, Kotlin, ZIO, Arrow, TypeScript, Kafka, Kubernetes, Python, PyTorch
