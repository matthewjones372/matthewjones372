### Hi, I'm Matt

I write typed functional code on the JVM, in Scala and Kotlin, and some Python for ML.

The biggest thing here is [tweet-street](https://github.com/matthewjones372/tweet-street), a small bank in four services: accounts as actors on a three-node cluster, transfers as sagas, screening, two-person approvals, and a chaos run that checks the books still balance afterwards.

It runs on a few small Kotlin libraries I wrote to see how ideas hold up: [lark](https://github.com/matthewjones372/lark) (effects, actors and clustering on virtual threads), [pelican](https://github.com/matthewjones372/pelican) (HTTP endpoints as values), [proofload](https://github.com/matthewjones372/proofload) (load testing) and [kimney](https://github.com/matthewjones372/kimney) (compile-time mapping). [petshop](https://github.com/matthewjones372/petshop) is a smaller service that tries them out with notes on whether each one helped.

Elsewhere: [verdict](https://github.com/matthewjones372/verdict), a Scala 3 rules engine that reads rules from lambdas with a macro; a [ZIO HTTP API over four film universes](https://github.com/matthewjones372/starwars-api) in Scala; [estate](https://github.com/matthewjones372/estate), a TypeScript dashboard that puts what you need for each service on one page; and some [ML work](https://github.com/matthewjones372/winning-ticket-search) from my MSc.

Scala, Kotlin, ZIO, Arrow, TypeScript, Kafka, Kubernetes, Python, PyTorch
